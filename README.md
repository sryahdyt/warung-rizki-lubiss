## ✨ Fitur-Fitur

### 1. KASIR
- Pilih barang, klik, langsung masuk keranjang
- Kategori: Semua, Makanan, Minuman, Sembako
- Ada Search, biar cari barang cepet
- Total belanja otomatis
- Diskon: No Diskon, Diskon 5%, Diskon 10%
- Pembayaran: Tunai & Hutang
- Input Uang Pembeli, kembalian otomatis

### 2. STOK
- Sisa stok otomatis berkurang kalo barang kejual
- Gak ada lagi barang tiba-tiba habis pas ada yang beli

### 3. HUTANG / BON
- Catat siapa yang ngutang, berapa, kapan
- Ada pengingat "Belum Dibayar"
- Hutang gak ada yang kelewat lagi

### 4. LAPORAN
- Omset Hari Ini
- Jumlah Transaksi
- Belum Dibayar
- Laporan rapi, tanpa buku tulis

### 5. ATUR
- Tambah barang baru
- Atur harga & stok
- Atur nama warung
